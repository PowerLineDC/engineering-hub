# DKC Loader

Локальный загрузчик каталога ДКС для наполнения инженерной базы Engineering Hub.

## Принципы

- не использует API ДКС;
- обходит только разрешённые стартовые URL и страницы каталога;
- соблюдает `robots.txt`;
- ограничивает частоту запросов и число параллельных запросов;
- повторяет временно неудачные запросы с backoff;
- хранит состояние обхода и позволяет продолжить после остановки;
- не создаёт значения, которых нет в источнике;
- отсутствующие характеристики сохраняются как `null` и попадают в журнал неполноты;
- сохраняет исходный URL каждой сущности;
- исключает дубликаты по артикулу/URL;
- отделяет сбор данных от записи в `manufacturers/dkc/`.

## Первый целевой каталог

CQE N: https://www.dkc.ru/ru/catalog/2095/

Для первого теста используются только нужные группы компонентов, без собранных корпусов и архивных моделей.

## Статус

Каркас загрузчика создан. Перед массовым запуском необходимо локально проверить фактическую HTML-структуру карточек и пагинацию каталога.
