# DKC Loader

Локальный загрузчик публичного каталога ДКС для наполнения инженерной базы Engineering Hub.

## Принципы

- не использует API ДКС;
- работает только с публично доступными страницами каталога;
- соблюдает `robots.txt`;
- идентифицирует себя как `EngineeringHub-DKC-Loader`;
- ограничивает частоту запросов и число параллельных запросов;
- повторяет временно неудачные запросы с backoff;
- хранит состояние обхода и позволяет продолжить после остановки;
- не создаёт значения, которых нет в источнике;
- отсутствующие характеристики сохраняются как `null` и попадают в журнал неполноты;
- сохраняет исходный URL каждой сущности;
- исключает дубликаты по артикулу/URL;
- отделяет сбор данных от записи в `manufacturers/dkc/`;
- не переходит на внешние домены.

## Ограничения обхода

Загрузчик использует консервативный режим обращения к сайту:

- задержка между запросами;
- ограниченное число одновременных запросов;
- ограничение общего числа страниц;
- тайм-аут запросов;
- повтор только временно неудачных запросов;
- экспоненциальная задержка между повторными попытками;
- сохранение состояния обхода;
- возможность продолжить после остановки;
- отдельные журналы ошибок и неполных данных.

Перед массовым запуском необходимо проверить фактическую HTML-структуру страниц каталога и карточек товаров.

## Первый целевой каталог

CQE N: https://www.dkc.ru/ru/catalog/2095/

Для первого теста используются только нужные группы компонентов, без собранных корпусов и архивных моделей.

## Статус

Каркас загрузчика создан. Первый запуск выполняется в режиме `dry_run`, чтобы проверить обнаружение страниц, пагинацию и извлечение данных до массовой записи в инженерную базу.
